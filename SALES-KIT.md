# Refill Desk — Pilot Sales Pack

## Short product description
Refill Desk is a simple pharmacy workflow app for tracking customer refill dates, medicine stock batches, orders, expiry dates and udhaar balances from one device.

## Pilot offer
**Proposed price: ₹999/month.** Start with a guided demo and a single-device pilot. Paid in-app checkout is not enabled yet, so do not advertise instant online payment or automatic subscription activation.

## Honest feature list
- Customer and refill tracking
- Medicine stock and batch records
- Expiry visibility
- Order workflow and batch-aware stock deduction
- Udhaar ledger
- Printable operational receipts
- JSON backup and restore

## Not included in the current pilot
- Automatic WhatsApp delivery
- Cloud backup or cloud database
- Multi-user accounts or cross-device sync
- GST-compliant tax invoicing
- Online payment / automatic paid-plan activation
- Certified regulatory or accounting compliance

## 30-second demo script
"Refill Desk helps a pharmacy keep customer refill dates, medicine batches, expiry information, orders and udhaar records together. It runs locally on one device, so the store keeps control of its data. You can export a JSON backup and restore it if needed. This is a guided pilot, and we will first test the workflow with sample data before any real store records are entered."

## Before onboarding a store
1. Show the app with demo/sample data only.
2. Explain that data stays in that browser/device and does not sync to another device.
3. Show Settings → Data Backup & Recovery → Export All Data (JSON).
4. Explain that backups contain business/customer information and must be kept securely.
5. Do not promise automatic WhatsApp, cloud sync, multiple staff logins, or GST invoices.
6. Do not accept payment as an in-app subscription until verified checkout is deployed.
7. Get the store owner to validate all workflows and applicable compliance requirements.

## First-run checklist
- Confirm store name, address and phone in Settings.
- Export an initial backup before entering any actual records.
- Enter only test data during the demo.
- Add stock with correct batch, expiry, quantity and price.
- Test a sale and confirm the correct batch quantity is deducted.
- Test an udhaar entry and settlement.
- Export a backup and test restore only with disposable data.
